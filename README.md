# 📦 Guía de Instalación

Este documento explica cómo instalar y ejecutar el proyecto en un entorno local.

---

## ✅ Requisitos previos

Asegúrate de tener instalados:

- **Git**
- **Node.js** (versión recomendada: 20+)
- **npm**, **pnpm** o **yarn**

---

## 📥 Clonar el repositorio

```bash
git clone https://github.com/camilo51/taller-git-ci-3223877-CristianPereira.git proyecto

cd proyecto
```
---

## 📦 Instalar dependencias

```bash
npm install
```
---
## 🧪 Ejecutar pruebas

```bash
node --test
```
